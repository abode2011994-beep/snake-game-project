# Snake Game 🐍

## About
This is a classic Snake Game built using HTML, CSS and JavaScript.

## How to Play
- Use the arrow keys to control the snake.
- Eat the food to grow longer.
- Avoid hitting the walls or yourself.
- Try to get the highest score!

## Technologies
- HTML
- CSS
- JavaScript
